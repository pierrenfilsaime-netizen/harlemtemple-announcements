Data for the announcements screen (harlemtemple-announcements.netlify.app). Netlify does not publish this branch,
so changes here cost no Netlify credits. Screens pick them up on their own.

- content.json: slides, weekly schedule and service times. Checked every 10 minutes. Rules: PROGRAM-UPDATES.md on main.
- media/: flyers and photos used by content.json (paths like "media/flyer.jpg").
- birthdays.json: rewritten every Sunday from the church calendar's "- HBD" events (Wednesday to Tuesday).
